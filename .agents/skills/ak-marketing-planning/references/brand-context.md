# Brand & Context Understanding Phase

**When to skip:** If provided with brand context or existing strategy docs, skip this phase.

## Core Activities

### Brand Context Extraction
- Reuse the relevant brand authority. Use an installed context extraction script only when its expected paths match the project.
- Understand brand voice, tone, and personality
- Review visual identity (colors, typography, imagery)

### Context Discovery

Read repository instructions and follow the project's documentation navigation. Locate current sources by role rather than assumed filename:

1. **Brand authority**
   - Brand voice and tone, visual identity, messaging, content pillars, legal, and approval constraints
2. **Marketing authority**
   - Strategy, positioning, target audiences, campaign history, performance, and learnings
3. **Business and product authority**
   - Goals, offerings, value propositions, customer evidence, and current priorities

Verify these sources against current assets, data, and provider state. If a required authority is absent or conflicting, ask the user instead of inventing it.

### Existing Campaign Analysis
- Review past campaign performance
- Identify successful patterns and learnings
- Note failed approaches to avoid
- Understand channel mix and ROI

### Asset Inventory
- Review existing marketing assets
- Identify reusable content and templates
- Note gaps in asset library
- Understand asset creation capabilities

### Integration Planning
- Identify how campaigns integrate with sales process
- Map marketing automation and CRM touchpoints
- Understand attribution and tracking setup
- Consider cross-channel coordination

## Best Practices

- Start with the discovered brand authority before campaign planning
- Document learnings for consistency
- Note any brand inconsistencies to address
- Consider impact on existing initiatives

## Quick Reference

**Content Pillars:** 3-5 core themes aligned with business goals

**Content Types:** Blog, video, podcast, social, email

**Audit Actions:** Keep, Update, Consolidate, Redirect, Delete

## Workflow

### Content Strategy Workflow
1. Reuse the current content inventory, research, and approved brief; audit only material gaps.
2. Identify audience, funnel stage, source evidence, and intended outcome for each content item.
3. Choose pillars supported by audience needs and production capacity.
4. Map clusters only where related content serves distinct search or customer intent.
5. Create the requested calendar with purpose, format, and requested owner/due date; flag unassigned ownership honestly.
6. Define production workflow
7. Set measurement framework

### Blog Planning Workflow
1. Reuse current keyword evidence; resolve an installed SEO capability only for missing search-intent evidence.
2. Select template based on intent
3. Create content brief
4. Outline → Draft → Edit → verify the requested artifact. Publish only when authorized for the target channel.

### Content Repurposing
- Blog → Social posts, email sequence, video script
- Podcast → Blog post
- Webinar → Multiple blogs

## Best Practices

1. Lead with value, not promotion
2. Match content to buyer journey stage
3. Maintain consistent publishing schedule
4. Update evergreen content quarterly
5. Repurpose before creating new
6. Measure content ROI, not just traffic
